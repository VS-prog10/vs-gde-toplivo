# ⛽ VS Где Топливо — Telegram-бот

Краудсорсинговый Telegram-бот для поиска заправок и цен на топливо.
Пользователи сами обновляют данные — бот показывает, где есть бензин и по какой цене.

## 🎯 Что умеет

- 📍 GPS-поиск ближайших АЗС
- 🏙 Поиск по городам Подмосковья
- 🔎 Фильтр по марке топлива (АИ-92, АИ-95, ДТ, GAS)
- 💰 Сортировка по цене
- ⭐ Избранные заправки
- 🗺 Карта и маршрут
- ➕ Краудсорсинг — пользователи добавляют данные
- 📊 Профиль и рейтинг

## 🚀 Быстрый старт

1. Клонируйте репозиторий:
   git clone https://github.com/VS-prog10/vs-gde-toplivo.git

2. Установите зависимости:
   pip install -r requirements.txt

3. Получите токен бота у @BotFather

4. Задайте переменную окружения BOT_TOKEN

5. Запустите:
   python bot.py

## 📦 Технологии

- Python 3.10+
- pyTelegramBotAPI
- SQLite
- Amvera (хостинг)
